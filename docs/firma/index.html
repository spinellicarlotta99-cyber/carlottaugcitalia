  1. In Gmail: Impostazioni (ingranaggio) → Mostra tutte le impostazioni → Firma.
  2. Crea una firma nuova o apri quella esistente, cancella il contenuto.
  3. Incolla (Ctrl+V / Cmd+V) e premi “Salva modifiche” in fondo.
