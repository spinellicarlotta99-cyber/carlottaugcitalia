Provare la pagina del corso sul tuo computer

Questa guida ti porta da zero a provare tutto il percorso della pagina: il video che si ferma a metà, il regalo, il form con le 4 domande e il bottone WhatsApp. Non serve saper programmare: si tratta di installare due programmi e copiare qualche comando.

Circa 30 minuti la prima volta, 2 minuti le volte dopoNon crea contatti veri nel portaleNon serve un account
Il tuo computer:
0 di 8 passi fatti

Visual Studio Code di solito è in inglese: nella guida trovi i nomi dei menu in inglese, con la traduzione tra parentesi.

  1. Installa Visual Studio Code 5 min

    È il programma da cui scaricherai il progetto e scriverai i comandi.

    1. Vai su code.visualstudio.com e clicca il grande bottone Download.
    2. Apri il file scaricato e trascina Visual Studio Code nella cartella Applicazioni. Aprilo dal Launchpad; se il Mac chiede conferma, clicca Apri.
    3. Apri il file scaricato, accetta la licenza e clicca sempre Next lasciando le opzioni come sono, poi Install. Alla fine aprilo.
    4. Se propone un tour iniziale, di accedere o di installare la lingua italiana, puoi chiudere tutto.

  2. Installa Git e Python 5–15 min

    Git serve a scaricare il progetto e a tenerlo aggiornato, Python a far partire la pagina sul tuo computer.

    1. In Visual Studio Code apri il menu Terminal → New Terminal (Terminale → Nuovo terminale). In basso si apre un riquadro con un cursore che lampeggia: è il terminale.
    2. Incolla questo comando (Cmd + V) e premi Invio:
    git --version && python3 --version
    • Se compaiono due righe tipo git version 2.39… e Python 3.9…: hai già tutto, vai al passo 3.
    • Se si apre una finestra che chiede di installare gli strumenti per sviluppatori da riga di comando: clicca Installa, accetta e aspetta la fine (anche 10 minuti). Installa sia Git sia Python. Poi incolla di nuovo il comando per controllare.
    1. Git: vai su git-scm.com/download/win, scarica Git for Windows (versione «64-bit»), aprilo e clicca sempre Next senza cambiare nulla, poi Install. Sono tante schermate: vanno bene tutte così come sono.
    2. Python: vai su python.org/downloads e scarica Python. Nella prima schermata dell'installazione spunta «Add python.exe to PATH» in basso, poi clicca Install Now.
    3. Chiudi e riapri Visual Studio Code, così vede i programmi appena installati.

  3. Scarica il progetto (clone) 2 min

    1. In Visual Studio Code premi Cmd + Shift + PCtrl + Shift + P: in alto si apre una barra di ricerca.
    2. Scrivi Git: Clone e premi Invio.
    3. Incolla questo indirizzo e premi Invio:
    https://github.com/spinellicarlotta99-cyber/carlottaugcitalia.git
    1. Si apre una finestra per scegliere dove salvarlo: scegli per esempio la cartella Documenti e clicca Select as Repository Destination (Seleziona come destinazione).
    2. Quando ha finito, in basso a destra chiede «Would you like to open the cloned repository?»: clicca Open (Apri).
    3. Se chiede «Do you trust the authors of the files in this folder?», clicca Yes, I trust the authors (Sì, mi fido).

    A sinistra ora vedi i file del progetto, tra cui docs, scripts e TEST-CORSO.md. Non serve un account GitHub: il progetto è pubblico.

  4. Apri il terminale nel progetto 1 min

    1. Menu Terminal → New Terminal (Terminale → Nuovo terminale).
    2. In basso si apre il terminale: la riga prima del cursore finisce con carlottaugcitalia. Vuol dire che sei nella cartella giusta.

    Per incollare nel terminale usa Cmd + VCtrl + V (o clic destro), poi premi Invio.

  5. Prendi l'ultima versione 10 sec

    Da fare ogni volta prima di provare, così hai le ultime modifiche:

    git pull

    Risponde Already up to date. se avevi già tutto, altrimenti elenca i file aggiornati. In entrambi i casi va bene.

  6. Avvia la pagina 1 min

    Incolla questo comando nel terminale:

    python3 scripts/dev-corso.py
    py scripts/dev-corso.py

    Se va tutto bene compare questo testo e il terminale resta occupato: è normale, deve restare aperto finché provi.

    Finto portale in modalità 'ok'. Apri: flusso veloce http://localhost:8080/corso/?videoID=1&src=adv&api=mock&pct=0.03&end=9999&reset=1 flusso reale http://localhost:8080/corso/?videoID=1&src=adv&api=mock&reset=1 I dati del form compaiono qui sotto. Ctrl+C per fermare.

    Il programma fa finta di essere il portale delle setter: i dati che inserisci nei form non arrivano a nessuno, compaiono solo qui nel terminale.

  7. Apri la pagina in Chrome 1 min

    Copia il link del flusso veloce e incollalo nella barra degli indirizzi di Chrome:

    http://localhost:8080/corso/?videoID=1&src=adv&api=mock&pct=0.03&end=9999&reset=1

    Con questo link il video si ferma dopo pochi secondi invece che a metà, così non devi guardarne minuti ogni volta. Il link flusso reale invece si comporta come per le persone vere: si ferma a metà.

    ImportanteUsa sempre i link che contengono api=mock. Senza, i dati vanno al portale vero e creano un contatto reale.

  8. Fai la prova 5 min

    Spunta ogni punto man mano che lo verifichi. Se qualcosa non torna, annota quale punto e fai uno screenshot.

Prove in più: quando il portale ha problemi

Servono a vedere cosa succede alle persone se il portale non risponde. Nel terminale premi Ctrl + C per fermare la pagina, poi avviala con uno di questi comandi e rifai la prova dal link con reset=1.

ComandoCosa deve succedere
python3py scripts/dev-corso.py --mode 400emailAll'ultimo passo il regalo torna alla domanda dell'email con un messaggio di errore.
python3py scripts/dev-corso.py --mode 400phoneIl regalo resta sulla domanda del telefono con un messaggio di errore.
python3py scripts/dev-corso.py --mode downIl portale non risponde: il video riparte lo stesso e WhatsApp si sblocca con il numero di riserva.
python3py scripts/dev-corso.py --mode 429Come sopra, per il caso di troppe richieste al portale.

Quando hai finito, e le volte dopo

  • Per fermare la pagina: clicca nel terminale e premi Ctrl + C (anche su Mac è Ctrl, non Cmd).
  • Le volte dopo: apri Visual Studio Code (riapre da solo il progetto) e rifai i passi 4, 5, 6 e 7. Un paio di minuti.

Se qualcosa non va

Cosa vediCosa fare
«command not found: git» / «git non è riconosciuto»Git non è installato: rifai il passo 2. Su Windows, dopo l'installazione chiudi e riapri Visual Studio Code.
«command not found: python3» / «py non è riconosciuto»Python non è installato: rifai il passo 2.
Scrivendo «Git: Clone» non compare nullaVisual Studio Code non trova Git: rifai il passo 2 e riapri Visual Studio Code.
«can't open file … dev-corso.py» o «No such file»Il terminale non è nella cartella del progetto. Menu File → Open Recent (Apri recenti), scegli carlottaugcitalia e rifai il passo 4.
«Address already in use»La pagina è già avviata in un altro terminale. Chiudi gli altri terminali (icona del cestino nel riquadro) oppure avvia con --port 8081 e nel link sostituisci 8080 con 8081.
Chrome dice «Impossibile raggiungere il sito»La pagina non è avviata: controlla che il terminale mostri ancora il testo del passo 6.
Il video resta neroIl servizio dei video non accetta ancora il tuo computer. Avvisa chi ti ha mandato questa guida.
Il video non si ferma maiLa pagina si ricorda che hai già lasciato i dati: usa il link con &reset=1 alla fine.
Dopo il form nel terminale non compare nullaNel link mancava api=mock e i dati sono andati al portale vero. Avvisa chi ti ha mandato la guida, così cancella il contatto.
