Provare la pagina del corso sul tuo computer

Questa guida ti porta da zero a provare tutto il percorso della pagina: il video che si ferma a metà, il regalo, il form con le 4 domande e il bottone WhatsApp. Installi un solo programma con l'assistente Claude: il resto (scaricare il progetto, installare quello che serve, avviare la pagina) lo fa lui, tu gli dai il permesso.

Circa 20 minuti la prima volta, 2 minuti le volte dopoNon crea contatti veri nel portaleNon serve saper programmare
Cosa ti serve: un Mac o un PC Windows, Chrome, e un account Claude con Claude Code incluso (piano Pro o superiore). 0 di 7 passi fatti

Visual Studio Code di solito è in inglese: nella guida trovi i nomi dei menu in inglese, con la traduzione tra parentesi. Dove c'è Cmd è per Mac, Ctrl per Windows.

  1. Installa Visual Studio Code 5 min

    1. Vai su code.visualstudio.com e clicca il grande bottone Download.
    2. Mac: apri il file scaricato e trascina Visual Studio Code nella cartella Applicazioni, poi aprilo dal Launchpad. Se il Mac chiede conferma, clicca Apri.
    3. Windows: apri il file scaricato, accetta la licenza e clicca sempre Next lasciando le opzioni come sono, poi Install. Alla fine aprilo.
    4. Se propone un tour iniziale o di accedere, puoi chiudere tutto.

  2. Installa l'estensione Claude Code 2 min

    1. Nella barra a sinistra clicca l'icona dei quadratini Extensions (Estensioni), oppure premi Cmd/Ctrl + Shift + X.
    2. Nella ricerca scrivi Claude Code.
    3. Scegli quella pubblicata da Anthropic (controlla il nome sotto il titolo) e clicca Install (Installa).

  3. Apri una cartella di lavoro 1 min

    Claude lavora dentro una cartella: è lì che scaricherà il progetto.

    1. Menu File → Open Folder… (Apri cartella). Su Mac può chiamarsi File → Open…
    2. Vai in Documenti, crea una cartella nuova chiamata progetti (bottone Nuova cartella nella finestra) e aprila.
    3. Se chiede «Do you trust the authors of the files in this folder?», clicca Yes, I trust the authors (Sì, mi fido).

  4. Apri Claude e accedi 2 min

    1. Clicca l'icona di Claude (la stellina arancione) in alto a destra nella finestra, oppure premi Cmd/Ctrl + Shift + P, scrivi Claude Code e scegli il comando per aprirlo.
    2. Si apre il pannello di Claude. La prima volta chiede di accedere: clicca il bottone di accesso, si apre il browser, entra con il tuo account Claude e conferma. Poi torna in Visual Studio Code.
    3. Ora in basso nel pannello c'è un campo dove scrivere a Claude.

  5. Chiedi a Claude di preparare tutto 5–15 min

    Copia questo messaggio, incollalo nel campo di Claude e invialo:

    Voglio provare in locale la pagina /corso del progetto https://github.com/spinellicarlotta99-cyber/carlottaugcitalia Non sono uno sviluppatore: spiegami ogni passo in parole semplici. 1. Controlla se ho Git e Python 3.8 o più recente. Se mancano, installali o guidami a installarli. 2. Clona il progetto in questa cartella. 3. Leggi TEST-CORSO.md e avvia scripts/dev-corso.py in background. 4. Dammi il link del "flusso veloce" da aprire in Chrome (deve contenere api=mock). Non modificare nessun file del progetto e non fare commit o push.
    • Claude chiede il permesso prima di eseguire ogni comando: leggi cosa vuole fare e clicca Yes (Sì). Se un comando ti sembra estraneo alla prova, clicca No e chiedigli perché.
    • Su Mac può aprirsi una finestra che chiede di installare gli strumenti per sviluppatori: clicca Installa e aspetta la fine (anche 10 minuti), poi scrivi a Claude «fatto».
    • Su Windows Claude può farti scaricare degli installer (Git, Python): aprili e clicca sempre Next. Per Python spunta «Add python.exe to PATH» nella prima schermata. Poi scrivi a Claude «fatto».

    Alla fine Claude ti risponde con un link che inizia con http://localhost:8080/corso/.

  6. Apri la pagina in Chrome 1 min

    Copia il link che ti ha dato Claude nella barra degli indirizzi di Chrome. Deve essere così:

    http://localhost:8080/corso/?videoID=1&src=adv&api=mock&pct=0.03&end=9999&reset=1

    Con questo link il video si ferma dopo pochi secondi invece che a metà, così non devi guardarne minuti ogni volta.

    ImportanteUsa sempre link che contengono api=mock. Senza, i dati vanno al portale vero e creano un contatto reale.

  7. Fai la prova 5 min

    Spunta ogni punto man mano che lo verifichi. Se qualcosa non torna, annota quale punto e fai uno screenshot.
